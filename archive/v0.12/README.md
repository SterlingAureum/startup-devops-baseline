# Historical v0.12 snapshot material

This directory preserves the previous CI, operational scripts, contracts,
examples, evidence and version documents. It also contains copies of operator
notes replaced by current instructions. It is reference material, not an
installed or supported command surface.

The supplied source archive was associated by its owner with tag `v0.12.4` and
commit `d14742c00e59dd31801dffe0c045a695697e077f`; the source archive had no Git
metadata, so that association was not independently verified here. This
snapshot also includes the four legacy workflow switch edits from the first
unmerged standard-delivery increment. Its five new workflow candidates remain
outside the archive and have been revised for the current structure.

The temporary CI compatibility patch is not required or included.

Moving files does not establish that old evidence is complete or that old
operations are reusable. Existing private state and account facts are not
reconstructed. For historical execution context, consult the original tag and
its paths. Relocated scripts have their original relative-root assumptions and
must not be executed in place.

Current workflows do not run archive validators or discover archive tests.
Archives are still included in repository secret scanning. Future case-library
work can select and verify examples independently.
