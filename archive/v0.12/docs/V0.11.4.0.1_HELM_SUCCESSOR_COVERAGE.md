# v0.11.4.0.1 Helm Successor Coverage

## Finding

The complete quality gate reached the Helm-only branch in
`scripts/validate-v0.11.3.4-unified-feature-revision-rendering.sh` and failed
with:

```text
Stable child Application set changed
```

v0.11.4.0 correctly added `observability-views` as the sixth local child
Application. The historical validator's static branch had been made
successor-aware, but its Helm-render branch still expected the v0.11.3.4 set of
five children. The producer environment did not contain Helm, so that branch
was skipped during package production.

This is a validator migration defect. It is not an Argo CD, Grafana,
PrometheusRule, Dashboard, or Kubernetes runtime-resource defect. Removing
`observability-views` would hide the defect and is forbidden.

## Repair

The historical validator now keeps its original five-child expectation when
the v0.11.4.0 successor contract is absent. When that successor is present, it
requires the six-child set and verifies that `observability-views` uses:

- `HEAD` in the stable render;
- the same resolved full feature SHA as namespace guardrails and demo-api in
  the feature render.

Argo Rollouts, ingress-nginx, and monitoring remain independently pinned to
their external Chart versions.

## Regression

The new focused validator supplies a deterministic fake Helm executable and
forces the historical validator through the previously skipped render branch.
This keeps the regression executable even when the package producer does not
have Helm installed.

Run:

```bash
./scripts/validate-v0.11.4.0.1-helm-successor-coverage.sh
./scripts/validate-ci-quality-gates.sh
```

After both pass, resume the original v0.11.4.0 `APPLY.md` at the first command
that failed. No cluster rollback, Argo CD deletion, or v0.11.4.0 reapplication
is required.

## Boundary

This repair changes validators, contracts, and documentation only. It changes
no monitoring value, Grafana runtime, Dashboard, recording rule, Application,
AWS desired state, Rollout behavior, release workflow, or production
automation.
