# v0.11.9.3.6.6.1 aws-test successor validation repair

The reviewed promotion PR correctly copied the immutable aws-dev release into
`aws-test.yaml`, but historical gates still required that candidate to remain
absent forever. This repair changes those gates from a permanent absence check
to an exact two-state allowlist: the historical aws-test file or the reviewed
promoted file. Any other bytes, including partial identity edits, fail closed.

aws-prod remains pre-promotion. This package does not dispatch or update the
existing promotion PR, merge it, access AWS/Kubernetes, generate traffic, or
tear down aws-dev.

After this repair is merged into protected main, update the existing promotion
PR branch from main and rerun its checks. Confirm that its only changed file is
`apps/demo-api/helm/values/releases/aws-test.yaml` before merge.
