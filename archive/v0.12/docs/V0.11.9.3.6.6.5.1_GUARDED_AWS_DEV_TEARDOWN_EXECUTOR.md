# v0.11.9.3.6.6.5.1 guarded aws-dev teardown executor

The implementation contract records the pre-executor preflight only as design
evidence. After this increment merges, the operator must generate a new
preflight on the new exact main SHA. The executor binds that fresh fingerprint
to a fresh UTC window and reruns the read-only preflight immediately before
either verify or execute. A
verify invocation cannot call the destroy wrapper. Execute additionally needs
`CONFIRM_AWS_DEV_TEARDOWN_EXECUTION=execute-reviewed-aws-dev-teardown`; callers
must not set the lower-level destroy confirmation themselves.

The maximum window is four hours and at least fifteen minutes must remain. Use
a new window after this increment is merged. Capture verify and execute output
in separate private files. Approval of verify does not approve execute.

Successful teardown does not run the residual-cost audit and does not create
aws-test. Audit remains the next separately reviewed phase.
