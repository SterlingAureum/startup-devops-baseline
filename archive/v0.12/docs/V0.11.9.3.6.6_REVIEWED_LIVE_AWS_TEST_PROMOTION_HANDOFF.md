# v0.11.9.3.6.6 reviewed live aws-test promotion handoff

The successful aws-dev live qualification is recorded in the reviewed
`v0.11.9.3.6.5.2` contract, but the manual promotion entrypoint previously
accepted only legacy workflow IDs or a Qualification Bundle. This increment
adds a narrow mode that validates the committed live contract and immutable
aws-dev release before preparing an aws-test release-only pull request.

The workflow does not access AWS or Kubernetes, merge its pull request, deploy
aws-test, generate traffic, promote a Rollout, or tear down aws-dev. It requires
the exact protected-main SHA and permits only `aws-dev -> aws-test`.

After this increment is merged to protected `main`, dispatch with:

```bash
git switch main
git pull --ff-only origin main
test -z "$(git status --short)"

export CONTROL_PLANE_SHA="$(git rev-parse HEAD)"
export REVIEWED_LIVE_CONTRACT_PATH='delivery/contracts/v0.11.9.3.6.5.2-aws-dev-runtime-qualification-execution.json'
export REVIEWED_LIVE_CONTRACT_SHA256="$(sha256sum "$REVIEWED_LIVE_CONTRACT_PATH" | awk '{print $1}')"

test "$REVIEWED_LIVE_CONTRACT_SHA256" = \
  'a5994ebce978e55842dabe22cfbb6c48adcfaf61fa46503d06001a6cc3b2b92e'

gh workflow run demo-api-promote-environment.yaml \
  --ref main \
  -f source_environment=aws-dev \
  -f target_environment=aws-test \
  -f qualification_mode=reviewed-live-contract \
  -f reviewed_live_contract_path="$REVIEWED_LIVE_CONTRACT_PATH" \
  -f reviewed_live_contract_sha256="$REVIEWED_LIVE_CONTRACT_SHA256" \
  -f release_id=demo-api-cf0a6bcbc466-cdffd3d71763 \
  -f control_plane_sha="$CONTROL_PLANE_SHA"
```

Do not supply legacy evidence or Qualification Bundle inputs. Review the
resulting PR and require that only
`apps/demo-api/helm/values/releases/aws-test.yaml` changes. Merging that PR,
destroying aws-dev, and creating or qualifying aws-test are separate
checkpoints with separate approvals.
