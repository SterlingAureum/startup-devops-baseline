# v0.11.9.3.6.7.3.1 aws-test state-classification repair

## Incident outcome

The separately approved `.7.3` operation applied the exact reviewed saved
plan successfully. Terraform apply and state-list stderr were empty, all 90
planned create addresses were present, and local state contained no additional
managed address. The executor nevertheless exited `1` before EKS and Secret
post-checks because it required every state-list address to appear in
`plan.resource_changes`.

The seven additional addresses are Terraform read-only data sources:

- three `aws_caller_identity` instances;
- three `aws_partition` instances;
- one `aws_route53_zone` instance.

These provider/configuration lookups legitimately persist in state without
appearing as resource changes. They do not represent seven extra AWS resources.

## Repair boundary

The repair classifies state addresses using the raw state resource mode. It
requires every planned create, rejects every additional managed or unclassified
address, and accepts only the exact reviewed data-source types and counts. It
also binds the original plan, apply output, failed result and resulting state
by SHA-256 without committing raw identities or private paths.

The original saved plan has already been consumed. The `.7.3` executor must
not be rerun.

## Post-merge recovery

After merge, run `.7.3.1 verify` on clean exact protected main. This phase is
local-only, reclassifies the original captured state, and leaves recovery
execution unauthorized.

After separate approval, `.7.3.1 execute` may perform only:

- STS caller-identity verification;
- EKS cluster inventory and aws-test DescribeCluster;
- EKS ACTIVE and reviewed public `/32` checks;
- Secrets Manager DescribeSecret metadata verification.

It runs no Terraform command and performs no AWS mutation. It does not read a
Secret value or run Kubernetes, Argo CD, GitOps bootstrap, traffic,
qualification, promotion or teardown.

## Failure handling

Any repository, evidence, state, account, EKS, CIDR or Secret drift stops.
Preserve both original and resume evidence plus local state. Never retry apply,
replan, destroy or edit state to force success.
