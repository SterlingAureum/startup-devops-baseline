# v0.12.2.4.2 Quality-gate History Deduplication

## Evidence and outcome

The first complete local run after v0.12.2.4.1 spent 818.612 seconds before it
stopped on an ignored private `terraform.tfvars`. It had not reached the new
v0.12.2.4.1 root entrypoint. The log also showed the same v0.11 validators
running dozens of times because all 168 historical validators were launched
directly while many successors also launched predecessors.

This increment preserves the complete validator inventory but executes only
112 maximal v0.11 entrypoints that are not already covered by the v0.12
branches. Static validation proves that all 168 v0.11 validators remain
reachable. The calculated v0.11 execution count falls from 866 to 176, and the
whole root validator graph falls from 951 to 245 executions.

The v0.12.3.1 successor adds one routing orchestrator above this graph. The
current full path therefore contains 246 effective validator executions and
three v0.12 orchestration layers while retaining the same 176 v0.11 and 25
historical v0.12 executions.

The old root registration text remains in non-executing heredoc manifests so
historical contracts that verify registration markers continue to see their
exact paths. The new call-graph checker ignores those manifests when deciding
what actually executes.

## Tracked Terraform formatting

Repository validation now obtains Terraform targets from `git ls-files` and
passes only tracked `.tf`, `.tfvars`, and `.tfvars.json` files to
`terraform fmt -check`. Ignored private inputs remain outside CI parity and are
not read or reformatted. `validate-terraform.sh` requires Terraform, while the
historical compatibility validator retains its previous optional behavior when
Terraform is not installed.

## Boundaries

- Existing v0.11 validator implementations are unchanged.
- The compatibility validator changes only its formatting command delegation.
- Workflow triggers and required-check names are unchanged.
- Change-impact routing and image-publish deduplication are implemented by the
  v0.12.3.1 successor.
- No AWS command, Terraform init/plan/apply, state mutation, retry, or recovery
  authority is added.

## Validation

Run structural validation without replaying history:

```bash
bash scripts/validate-v0.12.2.4.2-quality-gate-history-dedup.sh --structure-only
```

Run the full repository gate with its normal tool prerequisites:

```bash
bash scripts/validate-ci-quality-gates.sh
```

The final line reports total elapsed seconds. The historical orchestrator also
reports compatibility, v0.11, and v0.12 stage durations separately.
