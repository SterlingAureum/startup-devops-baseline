# v0.9.5 AWS ALB Progressive Delivery and Runtime Evidence

## Delivered

- GitOps-managed Argo Rollouts in the reusable AWS platform base.
- aws-test and aws-prod weighted ALB canary policies.
- Canary-local Web AnalysisRuns for database readiness and release identity.
- Release identity arguments bound into each AnalysisRun.
- Explicit Argo CD ownership boundaries for Rollout-mutated Services and ALB
  annotations.
- Restricted local runtime evidence collection and strict evidence validation.
- Dual static/runtime evidence enforcement before cross-environment Promotion
  PR creation.
- Local declaration, schema, tamper, expiry, and environment-isolation tests.

## Safety Decisions

- aws-dev remains a Deployment to preserve the validated cloud baseline.
- GitHub-hosted evidence, promotion, and rollback jobs receive no EKS access.
- The EKS endpoint allowlist is not widened for ephemeral GitHub runner IPs.
- Runtime evidence is reviewed in Git and contains no credentials or cluster
  connection material.
- v0.9.5 does not create test or production infrastructure or claim that an
  unapplied Rollout has passed live validation.
- The minimal Web provider does not replace the full observability platform
  planned for v1.0.
