# v0.11.6.0 Centralized Logging and Minimal Tracing Foundation

## Outcome

v0.11.6.0 defines the implementation and acceptance boundary for centralized
logs and a minimal extensible trace path. It deploys no runtime component and
changes no application code. Exact component and Helm versions are deliberately
deferred until the increment that deploys each component, where they must be
pinned and rendered through the normal repository quality gates.

The preceding v0.11.5 line is accepted locally. The final repaired alert drill
proved the exact nine healthy inactive formal alerts, warning and critical
firing and resolved delivery, continued severity routing, equal-scope
inhibition, unequal-scope isolation, strict cleanup, and zero temporary
Kubernetes and Prometheus rule-inventory residuals.

External provider delivery and formal AWS execution remain deferred. They are
not prerequisites for starting the logging and tracing implementation.

## Meaning of centralized

Centralized logging means one queryable log path inside each environment. It
does not mean that local, aws-dev, aws-test, and aws-prod send telemetry to one
shared backend.

Each environment owns its own:

- collectors;
- Loki storage and retention;
- OpenTelemetry Collector boundary;
- Tempo storage and retention;
- credentials and NetworkPolicy;
- Grafana data-source connection;
- resource, scheduling, and cost profile.

This isolation prevents a development failure, retention change, credential,
or high-volume stream from crossing an environment boundary. A future global
or federated query layer can be added without changing the application JSON or
OTLP contracts.

## Component responsibilities

| Component | Responsibility | First runtime increment |
| --- | --- | --- |
| demo-api | JSON Lines on stdout/stderr and trace-context propagation | v0.11.6.1 and v0.11.6.2 |
| Grafana Alloy | Kubernetes Pod-log and Event collection | v0.11.6.1 |
| Loki | Environment-local log storage and query | v0.11.6.1 |
| OpenTelemetry Collector | Environment-local OTLP gateway, processing, filtering, and sampling | v0.11.6.2 |
| Tempo | Minimal environment-local trace storage | v0.11.6.2 |
| Grafana | Metrics, logs, traces, and release-identity correlation | v0.11.6.3 |

Alloy owns logs and Kubernetes Events. The upstream OpenTelemetry Collector
owns the trace gateway. This keeps trace ingestion vendor-neutral while
allowing the log collector to follow node-local Kubernetes files.

The application never writes a log file and does not require a logging
sidecar. It never calls Loki, Tempo, Jaeger, X-Ray, or a vendor-specific tracing
API from business logic.

## Structured application log contract

Every application log record is one valid JSON object on one stdout or stderr
line. Required fields are:

```text
timestamp
severity
message
service.name
service.version
deployment.environment.name
platform.release.id
platform.source.commit
container.image.digest
```

When a record is produced inside an active span, it also carries:

```text
trace_id
span_id
```

Bounded optional fields include the HTTP method, route template, response
status, duration, database system, and operation outcome. The route template,
not a raw URL containing arbitrary identifiers or query parameters, is used.

The following content is forbidden:

- request or response bodies;
- Authorization, Cookie, or credential values;
- raw SQL or database parameters;
- user identifiers;
- raw URL query strings;
- Secrets, tokens, or passwords.

Exceptions and stack traces may remain structured message fields, but they must
pass the same sensitive-data boundary.

## Loki label cardinality

Only bounded operational dimensions become Loki labels:

```text
environment
cluster
namespace
application
container
severity
```

Correlation values remain parsed JSON or structured metadata, not indexed
labels. This includes:

```text
trace_id
span_id
platform.release.id
platform.source.commit
container.image.digest
pod.uid
pod.ip
request.id
enduser.id
raw.url
```

Release identity is intentionally queryable without becoming an unbounded
Loki stream dimension. This prevents one stream per request, trace, Pod, image,
or release.

## Minimal trace contract

The first trace path is intentionally small:

```text
HTTP request
-> demo-api server span
-> PostgreSQL client span
-> OTLP
-> OpenTelemetry Collector
-> Tempo
```

The application accepts and propagates W3C Trace Context and exports OTLP. The
Collector owns sampling and filtering; sampling is not compiled into business
logic. Server and PostgreSQL client spans are required, but secrets, raw SQL
parameters, request bodies, and Authorization data are forbidden attributes.

This contract does not require multi-service topology, messaging traces,
service graphs, tail sampling, distributed HA, or object-storage-backed trace
retention. Those features can be added later at the SDK, Collector, or backend
layer.

## Metric, log, trace, and release correlation

Metrics, logs, and traces share these stable identity dimensions:

```text
service.name
service.version
deployment.environment.name
platform.release.id
platform.source.commit
container.image.digest
```

Metrics locate the affected service and release. Logs preserve that same
identity and provide a `trace_id`. The trace provides the HTTP server and
PostgreSQL client spans. Grafana correlation is implemented and validated in
v0.11.6.3; v0.11.6.0 defines only the contract.

The same release fields may exist in multiple environments, but each query is
served by that environment's backend. Cross-environment identity does not imply
shared storage.

## Environment profiles

| Environment | Profile | Persistence and retention | Claim |
| --- | --- | --- | --- |
| local | lightweight | disposable and short | functional development only |
| aws-dev | cost-optimized | bounded and short | live development qualification |
| aws-test | cost-optimized production parity | bounded and short | controlled Canary and SRE validation |
| aws-prod | production parity | explicit and policy-controlled | only after live v0.11 acceptance |

Every runtime increment must pin versions and document CPU and memory requests
and limits, storage class and capacity, retention and deletion behavior,
scheduling, NetworkPolicy, credentials, expected idle and validation-window
cost, teardown, and residual-cost checks.

No observability service receives a public endpoint by default.

## Implementation sequence

### v0.11.6.1

- emit bounded JSON Lines from demo-api;
- deploy environment-local Loki and Alloy;
- collect Pod logs and Kubernetes Events;
- prove parsing, label cardinality, release identity, security filtering, and
  zero public exposure.

### v0.11.6.2

- instrument the demo-api HTTP and PostgreSQL path with OpenTelemetry;
- deploy the environment-local OTLP Collector and minimal Tempo backend;
- configure W3C propagation and collector-owned sampling;
- prove server/client spans and absence of forbidden attributes.

### v0.11.6.3

- provision Grafana data sources and correlation links through GitOps;
- navigate metrics to release-bound logs and logs to traces;
- validate the complete local metric-log-trace-release path.

### v0.11.6.4

- replay the feature deployment from a clean local baseline;
- harden readiness, eventual consistency, cleanup, and diagnostics;
- close v0.11.6 without expanding into v0.11.7 SLO work.

## Acceptance boundary

v0.11.6.0 is accepted when its contract, documentation, historical v0.11
validators, and complete repository quality gate pass. It requires no local
cluster execution, monitoring redeployment, or image build because it changes
no runtime.

Runtime logs begin in v0.11.6.1, runtime traces begin in v0.11.6.2, local
correlation is accepted in v0.11.6.3, formal AWS execution remains v0.11.8,
and clean-room closure remains v0.11.9.

## Deferred

The following are outside this foundation:

- cross-cluster log or trace aggregation;
- multi-tenant or distributed-HA backends;
- long-term object storage;
- tail sampling and service graphs;
- messaging, model-inference, and GPU tracing;
- AI infrastructure and AIOps automation;
- OpenClaw integration.
