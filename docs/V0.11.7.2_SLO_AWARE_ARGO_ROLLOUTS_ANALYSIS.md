# v0.11.7.2 SLO-aware Argo Rollouts Analysis

## Decision model

Operational multi-window alerts remain independent of delivery. The local
Prometheus AnalysisTemplate now combines candidate-release evidence with stable
service budget protection:

| Metric | Policy |
| --- | --- |
| Canary scrape target | at least one target up |
| Canary eligible samples | at least 20 `GET /version` requests in 5m |
| Canary availability burn | at most 14.4 over 5m |
| Canary latency burn | at most 14.4 over 5m |
| Stable availability budget | 30d remaining budget greater than zero |
| Stable latency budget | 30d remaining budget greater than zero |

Candidate queries exactly match the Rollout annotation-derived
`expected-release-id`; stable budget queries exactly match
`job="demo-api-stable"`. Empty results and provider errors fail closed.

## Rollout sequence

The template runs after the 20% pause. At 50%, an indefinite human review pause
remains. Promotion from that pause starts the same complete gate again before
100%. A failed AnalysisRun stops advancement while stable continues serving.

The controller does not edit Git, create a rollback PR, or invoke Rollout undo.
Operators inspect the AnalysisRun, SLO Dashboard, alerts, and Runbooks before
choosing abort, retry, or later promotion.

## Local acceptance

A fresh release identity is required to produce a new ReplicaSet and
AnalysisRun, but the accepted application image may be reused. To remove the
local traffic/AnalysisRun race, choose the version once, start the checker in a
second terminal first, and then reconcile that exact version. The checker
waits for the matching Rollout annotation before opening either Service.

```bash
# Terminal 2: start this before the deployment command in terminal 1.
EXPECTED_APPLICATION_VERSION=v0.11.7.2.1-<unique-UTC-suffix> \
  ./scripts/check-local-slo-aware-rollout-analysis.sh

# Terminal 1: use the same literal application version.
TARGET_REVISION=feature/v0.11-observability-sre-baseline \
IMAGE_TAG=<accepted-demo-api-image-tag> \
APPLICATION_VERSION=v0.11.7.2.1-<unique-UTC-suffix> \
  ./scripts/deploy-local-feature-gitops.sh
```

The checker performs no promotion, abort, patch, deletion, image build, or Git
mutation. AWS web-provider AnalysisTemplates remain unchanged.
