# v0.11.9.2.2.3.1 successor-aware target query

The v0.11.9.2.2.3 release-scoped target-up query intentionally supersedes the
historical v0.11.3.2 job-only query. The old contract remains an immutable
record of its checkpoint, while its current-template assertion now selects the
release-scoped query when the v0.11.9.2.2.3 contract exists.

Active analysis, observability and local-deployment documentation now describes
the exact Candidate release label. Archived and historical checkpoint documents
retain their original query.

Applying and validating this repair performs no Kubernetes, traffic, Rollout or
AWS operation.
