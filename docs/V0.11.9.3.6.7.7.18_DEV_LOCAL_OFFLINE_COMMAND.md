# v0.11.9.3.6.7.7.18 aws-dev local offline command

Implementation baseline: `8604d32e5bc1d093323d7bb4c990fb4a1d5d2b3e`.

This checkpoint places a strict local `verify`/`execute` command boundary around
the `.7.7.17` restart-safe adapter and `.7.7.16` fixed fake. It does not add a
live backend, credential reader or live execution authority.

## Private command inputs

The command accepts one canonical bundle containing the exact phase, main,
verify envelope, offline approval, state-after hash and complete postcondition
set. The file must be the only entry in its owned `0700` directory and must be
an owned, single-link `0600` regular file. Size, inode, device and hash are
checked without following links.

`verify` reads the bundle and host UTC once, reloads the exact completed receipt
prefix and validates phase order, predecessor, state continuity, time window,
budget, saved-plan boundary and postconditions. It prints a redacted canonical
preflight but creates no attempt, calls no fake and writes no receipt.

The caller stores that preflight in a separate private directory and reviews
it before `execute`. The execute confirmation includes the exact phase.
`execute` rereads and rehashes both files, rereads the host UTC, revalidates the
receipt prefix and every bundle gate, and rejects an expired or drifted
preflight. It then invokes one exact `.7.7.16` fixed fake through `.7.7.17`.

## Canonical postcondition adaptation

Canonical JSON sorts object keys while the frozen in-memory protocol requires
the design-declared postcondition order. The command verifies the exact key set
and that every value is true, then reconstructs the in-memory dictionary in
the frozen stage order. The original canonical bundle bytes and their reviewed
SHA-256 remain unchanged.

Successful execution appends the same exclusive, fsynced
attempt/receipt/completion triplet defined by `.7.7.17`. A pending triplet,
changed prefix, replay, invalid state relation or uncertain attempt stops and
preserves all private inputs and receipts. There is no retry or repair.

## Deliberate non-live scope

The command may read strict local files and the host clock and may write only
synthetic receipt triplets. It does not read environment variables or
credentials and cannot invoke subprocesses, SDKs, AWS, Kubernetes or
Terraform. Output never includes private paths. All receipts remain
`simulation_only=true`, `live_execution_authorized=false` and unusable for live
authority.

Run:

```bash
bash scripts/validate-v0.11.9.3.6.7.7.18-dev-local-offline-command.sh
```

The validator checks source hashes, AST and privacy boundaries, runs 38 offline
tests and recursively replays `.7.7.17`. Tests include actual child-process
invocations and an eight-stage command chain producing 24 restart-safe files.
