# v0.12.2.2.0.2 Identity-Rebase Digest Encoding Repair

## Outcome

The first v0.12.2.2.0.1 command-free verification stopped at `State resources
digest changed`. It executed no AWS or Terraform command and created no
recovery output.

The state did not drift. Diagnostic recomputation showed that every recorded
digest used sorted compact JSON followed by exactly one LF byte (`0a`). The
executor generated the same sorted compact JSON but omitted that final byte.

This repair adds the required LF before hashing and fixes the encoding with a
regression test over the exact byte sequence `{"a":1}\n`.
