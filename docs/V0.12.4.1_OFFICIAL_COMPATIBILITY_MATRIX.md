# v0.12.4.1 Official Compatibility Matrix

## Outcome

This increment reviews official compatibility evidence for the versions frozen
by v0.12.4.0. The result is deliberately **blocked**, not failed: it prevents a
live upgrade from starting while the target and several supporting components
remain unresolved.

As reviewed on 2026-09-28, the Amazon EKS standard-support page lists 1.36 as
available but does not list the provisional next minor, 1.37. An upstream
Kubernetes release never grants authority to select an Amazon EKS version.
Therefore this increment does not select a target EKS minor.

This is a static, offline contract. It performs no network lookup at validation
time and is not a statement about the current live clusters.

CloudNativePG chart `0.29.0` resolves to application `1.30.0`; it must not be
misclassified as CloudNativePG 1.29. The four EKS managed add-ons remain
unpinned in Terraform, so their installed versions and target-compatible
versions require a fresh live inventory and official
`describe-addon-versions` lookup before an upgrade request can exist.

## Supportedness repair before EKS work

External Secrets 2.8 is compatible with Kubernetes 1.36 but is no longer a
supported release line. The reviewed destination is the 2.11 line, with the
publisher-recommended one-minor sequence `2.8 -> 2.9 -> 2.10 -> 2.11`.
Selecting exact patch versions, reviewing breaking changes, changing GitOps
declarations and executing upgrades belong to separate increments. This
maintenance must not share an EKS control-plane upgrade window.

The next increment also resolves chart-to-application mappings and official
supportedness for the Load Balancer Controller, Argo Rollouts,
kube-prometheus-stack and Barman Cloud plugin. Unknown compatibility continues
to block progress; it is not treated as implicit compatibility.

## Conditional EKS rollback

Amazon EKS now documents a bounded control-plane rollback mechanism. It is a
conditional recovery option, not the primary or automatic recovery path. A
future rollback would require fresh approval, AWS eligibility checks, a
supported previous minor, no more than one-minor distance and the documented
seven-day window. Managed nodes and add-ons are handled separately; application
or Terraform state rollback is not included.

## Gate and next checkpoint

The overall upgrade gate remains blocked for four exact reasons:

1. EKS 1.37 is not listed on the reviewed Amazon EKS standard-support page.
2. Exact installed and target-compatible managed add-on versions are unknown.
3. External Secrets 2.8 has reached end of life.
4. Several chart/application mappings or official supportedness records are unresolved.

No AWS, Terraform, Kubernetes, GitHub, EKS, add-on, controller or version
mutation is authorized. Next:
`v0.12.4.1.1-platform-supportedness-repair-design`.
