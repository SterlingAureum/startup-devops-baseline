# v0.9.6 Clean-Room Multi-Environment Validation

## Status

Implementation complete; live aws-test acceptance evidence pending.

## Purpose

Close the v0.9 multi-environment baseline with one reproducible and
cost-bounded live sequence:

```text
reviewed main
  -> re-qualify aws-dev
  -> create isolated aws-test
  -> promote one immutable digest
  -> complete ALB canary and AnalysisRun
  -> exercise PostgreSQL primary recovery
  -> destroy aws-test
  -> prove no continuing cost resources remain
```

aws-prod remains a complete Terraform, Kustomize, Helm, promotion, approval,
rollback, and progressive-delivery declaration. Live production creation is
not required for the portfolio v0.9 checkpoint.

## Delivered controls

- guarded create/resume apply for the independent aws-test Terraform root;
- environment-aware bootstrap and existing root deployment reuse;
- reviewed manual aws-test rollout completion with bounded pause count;
- aws-test GitOps, PostgreSQL, HTTPS, and runtime-evidence validation;
- generalized dev/test teardown that rejects aws-prod;
- exact AWS residual checks plus a tag-based secondary sweep;
- accepted Secrets Manager recovery-window tombstone semantics;
- final v0.9 evidence schema binding dev/test records to one artifact;
- final evidence hash, lifecycle ordering, tamper, and sensitive-field checks;
- failure recovery guidance that preserves Terraform and controller ownership.

## Acceptance still required

The implementation itself does not claim a live test. v0.9 is complete only
after the operator:

1. runs the sequence from reviewed `main`;
2. merges fresh aws-dev and aws-test evidence;
3. completes the CloudNativePG failover drill;
4. destroys aws-test;
5. passes the residual-cost audit; and
6. merges a valid v0.9.6 final evidence record.

## Non-goals

- no permanently running test or production portfolio cluster;
- no live aws-prod apply;
- no automatic canary promotion or automatic PR merge;
- no GitHub-hosted EKS access;
- no workstation public IP in Git;
- no remote Terraform state, full observability, SLO, or logging platform;
- no Secret, database, backup, certificate, or state promotion.
